Yes — admin rights are required for the tool to attach to the PURPLE client and manage client-side appearance data.

**Does it work on Windows 11?**
Yes — Windows 10 and Windows 11 (64-bit) are supported.

**Does it work with the ability application system?**
Yes — the tool supports both Appearance Apply (look only) and Ability Apply (look plus stats), matching the in-game Class Skin system.

**How do I update?**
